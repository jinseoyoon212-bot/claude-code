# 빛과 어둠의 마법 전쟁 (Godot 4.3, 3D)

대마법사가 되어 빛의 기사단과 함께 어둠의 군주 모르가스의 해골 군단을 막는 3D 전투 게임.
5웨이브를 버티면 마지막에 보스가 등장하고, 보스를 쓰러뜨리면 승리.

## 조작
| PC | 모바일 | 동작 |
|---|---|---|
| WASD / 방향키 | 왼쪽 화면 드래그 | 이동 |
| Space / 클릭 유지 | 공격 버튼 | 공격 (가까운 적 자동 조준) |
| Q | 결계 | 3.5초 무적 |
| E | 별빛 폭발 | 주변 적 피해 + 넉백 |
| R | 기사 소환 | 빛의 기사 2명 소환 |

## 구조
- `main.gd` 전장 생성, 웨이브, 영웅 조작, 투사체, 카메라
- `unit.gd` 모든 유닛(영웅·아군·적·수정)의 AI와 애니메이션
- `hud.gd` 체력바, 스킬 버튼, 가상 조이스틱, 시작/결과 화면
