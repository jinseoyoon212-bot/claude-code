# HYPER ARENA

PC 전용 1인칭 슈팅 데스매치 (Three.js / WebGL). 봇 9명과 먼저 25킬.

- 조작: WASD 이동 · 마우스 시점 · 좌클릭 발사 · 우클릭 조준 · Shift 달리기 · Space 점프 · R 재장전 · 1~4/휠 무기 교체 · Tab 점수판
- 개발: `npm install && npm run dev`
- 빌드: `npm run build` → `dist/`
- 배포: `main`에 푸시하면 GitHub Actions가 GitHub Pages로 배포 (Settings → Pages → Source: GitHub Actions)
