# Aurora Agent 🌈
무지개 오로라 얼굴이 말과 텍스트에 따라 표정·움직임을 바꾸는 AI 에이전트 (Electron).

- 실행: `npm install && npm start`
- exe 빌드(Windows): `npm run dist` → `dist/AuroraAgent-1.0.0-portable.exe`, `-nsis.exe`
- GitHub Actions(`Build Windows exe`)가 push 때 자동으로 exe를 빌드하고 Artifacts에 올립니다.
- 첫 실행 시 ⚙ 설정에 Anthropic API 키 입력. 기본은 명령/파일쓰기 전 승인 창, 설정에서 자동 실행으로 변경 가능.
